**この記事でわかること**

- 在宅ワークでホームルーターが向く人・向かない人の分かれ目
- 光回線・ホームルーター・テザリングを、用途別にどう使い分けるか
- 契約前に確認したい「エリア・通信品質・速度制限・端末代・解約条件」のポイントとチェックリスト

## 結論：Web会議が多いなら、まず「自宅で安定して使えるか」を確かめてから選ぶ

在宅ワークの回線選びで大事なのは、最大速度の数字よりも **自分の家で、仕事の時間帯に安定してつながるか** です。

- **光回線が引ける・工事を待てる人**：まず光回線を検討するのが基本です。有線でつなげるため、通信が混み合う時間帯の影響を受けにくい構成にできます
- **工事ができない・すぐに使い始めたい人**：ホームルーターが選択肢になります。ただし電波を使うため、住まいの場所や部屋によって通信品質が変わります。契約前にエリアを確認し、試せる期間や解約条件を把握してから決めましょう
- **在宅ワークが週1〜2日程度で、通信量が少ない人**：スマホのテザリングで足りる場合もあります（契約プランのデータ容量とテザリング条件の確認が前提です）

## Web会議に必要な通信量の目安（Zoom公式）

回線を選ぶ前に、「自分の仕事にどれくらいの通信が必要か」を知っておくと判断しやすくなります。Zoomは公式サポートページで、ミーティングの推奨帯域を次のように示しています（[Zoom system requirements: Windows, macOS, Linux](https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0060748)、2026年11月8日確認）。

| 用途 | 推奨帯域（上り／下り） |
|---|---|
| 1対1のビデオ通話（720p HD） | 1.2Mbps／1.2Mbps |
| グループのビデオ通話（720p HD） | 2.6Mbps／1.8Mbps |
| グループのビデオ通話（1080p HD） | 3.8Mbps／3.0Mbps |
| 画面共有のみ（映像なし） | 50〜75kbps |
| 音声のみ | 60〜80kbps |

ポイントは2つです。

- **上り（送信）も必要**：Web会議では自分の映像・音声を送るため、動画視聴と違って上りの通信量も使います
- **数字は「その時点で安定して出るか」が大事**：推奨帯域は大きな数字ではありませんが、回線が混み合って一時的に下がると、映像が止まったり音声が途切れたりします

ほかのツール（Microsoft Teams、Google Meetなど）を使う場合は、それぞれの公式ヘルプで推奨帯域を確認してください。

## 光回線・ホームルーター・テザリングの用途別比較

| 比べるポイント | 光回線 | ホームルーター | スマホのテザリング |
|---|---|---|---|
| 使い始めるまで | 開通工事が必要な場合がある | 端末が届けばコンセントに挿して使える | すぐ使える |
| 通信の安定性 | 有線でつなげられ、比較的安定しやすい | 電波を使うため、場所・部屋・時間帯で変わる | 電波と端末の状態で変わる。長時間はスマホの発熱・電池に注意 |
| 通信量の上限 | 一般に上限なしのプランが多い（契約内容で確認） | プランによる。「無制限」でも、混雑時などに速度制限がかかる場合がある | 契約プランのデータ容量とテザリング条件による |
| 向いている使い方 | 毎日のWeb会議、大きなファイルのやり取り | 工事ができない住まい、すぐ使いたい、引っ越しの予定がある | 週1〜2日程度の在宅、予備回線 |
| 契約前に確認すること | 提供エリア、工事日程、契約期間 | エリア、端末代の支払い条件、解約時の費用、利用場所の条件 | データ容量、テザリングの可否・追加料金 |

それぞれの細かい条件は、事業者・プランによって大きく変わります。表は一般的な傾向です。最終的には、契約を検討しているサービスの公式情報で確認してください。

## 契約前に確認したい5つのポイント

### 1. エリア：住所が提供エリア内か、部屋のどこに置くか

ホームルーターは基地局からの電波を受けて通信します。たとえばWiMAXの場合、UQ WiMAXの公式サイトに[サービスエリアのページ](https://www.uqwimax.jp/wimax/area/)があり、都道府県ごとのエリアマップを確認できます（2026年11月8日確認）。同じページには、エリア内でも屋内やビルの陰などでは通信できない、または速度が低下する場合があること、申込前にエリアを確認することが案内されています。

マップでエリア内でも、実際の電波状況は部屋や置き場所で変わります。窓際に置くなど、置き場所も含めて考えましょう。

### 2. 通信品質の変動：時間帯や周囲の利用状況で変わる

電波を使う回線は、同じ場所でも時間帯や周囲の利用状況によって通信品質が変わることがあります。「仕事をする時間帯に、Web会議が安定するか」を、試せる期間があれば実際に確かめるのが確実です。

### 3. 容量・速度制限：「無制限」の注意書きまで読む

「データ量無制限」とうたうサービスでも、注意書きに速度制限の条件が書かれていることがあります。たとえば、とくとくBBホームWi-Fiの公式ページでは、一定期間内に大量のデータ通信を利用した場合、混雑する時間帯の通信速度を制限する場合があると注記されています（[公式ページ](https://gmobb.jp/gmohomewifi/)、2026年11月8日確認）。大きなファイルを頻繁に送受信する人は、この条件を必ず確認しましょう。

### 4. 端末代：分割払いの回数と、途中で解約したときの扱い

ホームルーターは、端末代を分割で支払い、その分を月額料金から割り引く料金設計のものがあります。この場合、**途中で解約すると、残りの端末代の支払いが発生する可能性** があります。「違約金なし」と書かれていても、端末代の扱いは別のことがあるため、申込前に必ず確認してください。

### 5. 解約条件と利用場所：引っ越しや持ち出しの予定があるなら特に確認

- 解約時にかかる費用（違約金、端末代の残り、解約月の料金の扱い）
- 登録した住所以外で使えるか、使う場合に条件や追加料金があるか

帰省先や短期滞在先で使うことを考えている場合は、**利用場所の条件と、その期間だけ使った場合の総費用** を公式情報で確認してから判断しましょう。条件によっては、テザリングや滞在先の回線を使うほうが合理的なこともあります（帰省先からのテレワークについては「[帰省先テレワークでIP制限に入れない？出発前チェックリスト](kisei-telework-ip-seigen-checklist.html)」も参考にしてください）。

## ホームルーターが向いている人・向いていない人

### 向いている人

- 賃貸などで、光回線の工事ができない・許可が取りにくい
- 光回線の開通を待てず、すぐに在宅ワークの環境を整えたい
- 引っ越しの予定があり、工事のいらない回線を使いたい
- 住所がエリア内で、置き場所の電波状況も確認できる

### 向いていない人（光回線などを優先したい人）

- 毎日長時間のWeb会議があり、少しの途切れも避けたい
- 大容量のデータ（動画、デザインデータなど）を毎日のように送受信する
- 住まいがエリアの境目にある、または電波が入りにくい部屋で仕事をする
- 会社から有線接続などの回線条件を指定されている

工事不要のホームルーターの一例として、GMOインターネット株式会社の「とくとくBBホームWi-Fi」の主な仕様をまとめます（2026年11月8日時点、[公式ページ](https://gmobb.jp/gmohomewifi/)より）。

|---|---|
| 使い方 | 工事不要。端末にSIMカードを入れて、コンセントに挿して使う |

| 通信量 | データ量無制限とうたう一方、一定期間内に大量のデータ通信を利用した場合、混雑する時間帯の通信速度を制限する場合があると注記 |
| 月額料金 | 公式ページの画像で「月額5,170円（税抜）（税込5,687円）」と表示。最新の料金は公式サイトで確認してください |
| 初期費用など | 入会費0円、送料0円、事務手数料3,300円（税込） |
| 端末代 | 33,264円（税込）を36回の分割払い。分割相当分（月額924円）を割り引いた月額料金と説明 |
| 解約 | 解約違約金なしと記載。途中解約時の端末代の残りの扱いは、申込前に公式の注意事項で確認してください |
| 発送 | 平日15時30分、土日祝14時までの申込完了で最短即日発送（在庫状況により停止の場合あり） |
| 利用場所 | 公式ページの比較表に「登録先住所以外も使える」と記載。利用できる条件や、プラスエリアモードの利用料（使った月のみ1,100円・税込）なども公式で確認してください |
| 光回線への切り替え | 契約期間中いつでも違約金なしで「とくとくBB光」へ乗り換えられる「いつでもあんしん乗り換え保障」がある |

端末代が実質0円になるまでの利用期間について、公式ページ内に異なる表記（24か月・36か月）が見られました。申込前に、公式の料金説明と注意事項で最新の条件を確認してください。キャンペーン特典は時期によって変わるため、この記事では金額を掲載していません。最新の特典も公式サイトで確認してください。

## 契約前チェックリスト

申し込む前に、次の項目を確認しておきましょう。

- [ ] 住所が提供エリア内か（エリアマップで確認したか）
- [ ] ルーターを置く予定の部屋・場所で電波が届きそうか
- [ ] 自分の仕事に必要な通信量（Web会議の頻度・画質、ファイルのやり取り）を把握したか
- [ ] 「無制限」の注意書き（速度制限の条件）を読んだか
- [ ] 月額料金と、端末代の支払い方法（分割回数・割引の条件）を確認したか
- [ ] 途中で解約した場合にかかる費用（端末代の残りなど）を確認したか
- [ ] 登録住所以外で使う予定があるなら、その条件と追加料金を確認したか
- [ ] 会社やクライアントから、回線についての指定（有線接続、固定IPなど）がないか

固定IPでの接続を求められている場合は、回線とは別に固定IPの用意が必要になることがあります。詳しくは「[フリーランスに固定IPは必要？不要な条件とIP登録依頼メール例文](freelance-kotei-ip-hitsuyou-mail-template.html)」で解説しています。

## よくある質問

### Q1. ホームルーターでWeb会議はできますか？

Zoomの公式ページが示す推奨帯域（グループの720p HDで上り2.6Mbps・下り1.8Mbpsなど）を、仕事の時間帯に安定して満たせれば利用できます。ただし、電波を使う回線は場所や時間帯で通信品質が変わります。エリアと置き場所を確認し、試せる期間があれば実際の会議で確認するのが確実です。

### Q2. 「データ量無制限」なら、どれだけ使っても速度は落ちませんか？

そうとは限りません。公式の注意書きに、大量のデータ通信を利用した場合などに速度を制限する条件が書かれていることがあります。申込前に注意書きまで読んで確認してください。

### Q3. カフェなどで作業するときも、ホームルーターを持っていけば安全ですか？

ホームルーターは基本的に自宅に置いて使う機器で、利用場所の条件はサービスによって異なります。外出先での作業については、フリーWi-Fiの安全対策を「[カフェのフリーWi-Fiは危険？在宅ワーカーの安全対策とVPNの選び方](cafe-free-wifi-safety-vpn.html)」でまとめています。
