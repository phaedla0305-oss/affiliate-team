## フリーWi-Fiで起こりうるリスクとは（公的機関の注意喚起をもとに整理）

カフェやコワーキングスペースのフリーWi-Fiは便利ですが、自宅のWi-Fiとは違い「誰が同じネットワークにいるか分からない」環境です。総務省やIPA（情報処理推進機構）は、公衆無線LANの利用者に向けて注意を呼びかけています。

公的資料で挙げられている主なリスクは、次のように整理できます。

| リスク | どんなことが起こりうるか |
|---|---|
| 通信の盗み見（盗聴） | 暗号化されていない通信の内容を、同じネットワーク上の第三者に読み取られるおそれがある |
| なりすましアクセスポイント | お店のWi-Fiと似た名前の偽のアクセスポイントに接続させ、通信内容を盗み見たり偽サイトへ誘導したりする |
| 端末への不正アクセス | ファイル共有などの設定が有効だと、同じネットワーク内の他人から端末にアクセスされるおそれがある |
| 暗号化されていないWi-Fi | パスワードなしで接続できるWi-Fiは、通信が暗号化されていない場合がある |

また、店内にパスワードが掲示されているWi-Fiは、「暗号化されていても、同じパスワードを知っている人が多い」点にも注意が必要です。

ペルソナのように、クライアントの未公開デザインや契約書を扱うフリーランスにとっては、「自分の情報」だけでなく「預かっている他人の情報」を守る責任がある点が、会社員の私的利用とは異なるところです。

## まずは無料でできる基本対策（HTTPSの確認・自動接続オフ・OS更新・テザリングの活用）

VPNを検討する前に、お金をかけずにできる対策から始めましょう。多くのリスクは、次の設定と習慣で減らせます。

### 1. HTTPSで接続しているか確認する

ブラウザのアドレス欄が「https://」で始まり、鍵マークが表示されているサイトは、ブラウザとサイトの間の通信が暗号化されています。ログインやファイルのアップロードをするときは、必ず確認する習慣をつけましょう。

ただし、HTTPSは「通信が暗号化されている」ことを示すもので、「そのサイトが本物である」ことまでは保証しません。偽サイトもHTTPSに対応している場合があるため、ブックマークから開くなど、URLを自分で確かめることも大切です。

### 2. Wi-Fiの自動接続をオフにする

一度つないだWi-Fiに自動で再接続する設定のままだと、同じ名前の偽アクセスポイントに気づかずつながってしまうおそれがあります。

- 使い終わったフリーWi-Fiは「このネットワークを削除」しておく
- 接続するときは、お店が案内しているネットワーク名（SSID）と一致しているかを確認する

### 3. OS・ブラウザ・アプリを最新の状態にする

OSやブラウザの更新には、セキュリティ上の弱点（脆弱性）の修正が含まれていることが多くあります。自動更新をオンにし、外出前に更新が溜まっていないか確認しましょう。

### 4. ファイル共有をオフにし、「パブリック」設定にする

- **Windows：** フリーWi-Fiに接続するときは、ネットワークプロファイルを「パブリック」にする
- **Mac：** 「システム設定」の共有設定で、ファイル共有などを必要なとき以外はオフにする

<!-- 要確認: 最新版Windows／macOSでの設定項目の名称とメニュー位置 -->

### 5. 重要な作業はテザリングに切り替える

スマートフォンのテザリング（スマホを経由した通信）を使えば、不特定多数が使うWi-Fiを経由せずに通信できます。契約書の送受信やクライアントの管理画面へのログインなど、重要な作業のときだけテザリングに切り替えるのも現実的な方法です。

テザリング時は、スマホ側に推測されにくいパスワードを設定しましょう。データ通信量の上限や、契約プランでテザリングが使えるかもあわせて確認してください。

### 6. ログインまわりを強化する

- クラウドストレージやメールに**多要素認証（2段階認証）**を設定する
- パスワードの使い回しをやめ、パスワード管理ツールを使う

フリーWi-Fiに限らず、情報漏えいの多くはログイン情報の流出から始まります。ここを固めておくだけでも、被害の起こりにくさは大きく変わります。

### 7. 画面の盗み見・置き忘れに注意する

カフェでは、通信よりも「画面を後ろからのぞかれる」「席を離れたすきに端末を触られる」リスクのほうが身近かもしれません。

- のぞき見防止フィルターを使う
- 席を立つときは画面をロックする（Windowsなら「Windowsキー＋L」）
- 端末のディスク暗号化（WindowsのBitLocker／デバイスの暗号化、MacのFileVault）を有効にしておく

## VPNで防げること・防げないこと

VPN（Virtual Private Network）は、自分の端末とVPN事業者のサーバーとの間に「暗号化されたトンネル」をつくって通信する仕組みです。フリーWi-Fiで使う場合に期待できることと、期待できないことを分けて整理します。

### VPNで防げる（リスクを減らせる）こと

- **フリーWi-Fi上での通信の盗み見：** 端末からVPNサーバーまでの通信が暗号化されるため、同じWi-Fiに接続している第三者やWi-Fiの運営者から、通信内容を読み取られにくくなります
- **HTTPS非対応の通信の保護：** HTTPSに対応していないサイトやアプリの通信も、VPNサーバーまでの区間は暗号化されます
- **接続元IPアドレスの切り替え：** 通信先からは、自分の端末ではなくVPNサーバーのIPアドレスから接続しているように見えます（固定IP型のVPNなら、毎回同じIPアドレスで接続できます）

### VPNでは防げないこと

- **フィッシング詐欺：** 偽サイトに自分でIDやパスワードを入力してしまえば、VPNを使っていても情報は盗まれます
- **マルウェア（ウイルス）感染：** 不審な添付ファイルを開いたり、怪しいソフトを入れたりすることによる感染は防げません
- **画面の盗み見・端末の盗難や置き忘れ：** 物理的なリスクには効果がありません
- **パスワードの使い回しによる不正ログイン：** 別のサービスから漏れたパスワードを使われるケースは防げません
- **VPNサーバーから先の通信：** VPNサーバーから通信先までの区間は、通常のインターネット通信と同じです。HTTPSの確認は引き続き必要です

### VPNを使うときに知っておきたい注意点

- **VPN事業者を信頼する必要がある：** 通信はVPN事業者のサーバーを経由します。Wi-Fiの運営者の代わりにVPN事業者を信頼することになるため、運営元やログ方針の確認が欠かせません
- **通信速度が低下する場合がある：** 暗号化処理やサーバーを経由する分、通信が遅くなることがあります。大きなデザインデータを頻繁にやり取りする人は、事前に影響を確認しましょう
- **一部のサービスで使いにくい場合がある：** サービスによっては、VPN経由のアクセスを制限していることがあります

つまり、VPNは「フリーWi-Fiの通信区間を守る道具」であって、「情報漏えいをすべて防ぐ道具」ではありません。前の章の基本対策とセットで考えることが大切です。

## 会社員は要注意：会社支給PCでは情報システム部門のルールが優先

この記事は主に私物のPCで作業するフリーランスを想定していますが、会社員の方や、取引先から端末を貸与されている方は特に注意してください。

**会社支給のPCや業務用端末に、個人で契約したVPNソフトを入れるのは避けてください。** 社内のセキュリティポリシー違反になるおそれがあるほか、会社がすでに用意している社内VPNやセキュリティソフトと競合して、正常に動作しなくなる可能性もあります。

- 外出先での作業ルール（フリーWi-Fiの利用可否、テザリングの扱いなど）は、まず**情報システム部門に確認**する
- 会社指定のVPNがある場合は、そちらを使う
- フリーランスでも、クライアントからセキュリティ要件（利用してよいネットワーク、端末の条件など）が示されている場合は、その契約内容に従う

「自分のためにセキュリティを強化したつもり」が、規程違反になってしまうことは避けたいところです。

## あなたにVPNは必要？要・不要の判断チェックリスト

VPNが必要かどうかは、作業スタイルによって変わります。当てはまる項目を数えてみてください。

### 【A】VPNの導入を検討したほうがよい人

- [ ] 週に1回以上、カフェ・コワーキング・ホテルなどのフリーWi-Fiで作業する
- [ ] 未公開のデザインデータ、契約書、個人情報など、漏れると困るデータをフリーWi-Fi上でやり取りする
- [ ] テザリングだけではデータ容量や速度が足りず、フリーWi-Fiを使わざるを得ない
- [ ] クライアントのサーバーや管理画面が接続元IPアドレスで制限されており、固定IPでの接続を求められている
- [ ] 海外滞在中に、日本からの接続が前提のサービスを使う予定がある
- [ ] 私物のPCで作業しており、会社や取引先のルールに抵触しない

### 【B】今はVPNがなくても対応できる可能性が高い人

- [ ] フリーWi-Fiを使うのは月に数回程度で、メールやWeb閲覧が中心
- [ ] 重要なデータのやり取りは、自宅かテザリングのときだけに限定できる
- [ ] 使うサービスのほとんどがHTTPS対応で、多要素認証も設定済み
- [ ] 会社支給のPCで作業しており、会社指定の対策がある（→会社のルールに従う）

**判定の目安**
- 【A】に2つ以上当てはまる：VPNの導入を検討する価値があります。特に「IP制限」「海外からの接続」に当てはまる人は、固定IP型のVPNが候補になります
- 【B】が中心：まずは無料の基本対策を徹底し、テザリングと使い分けるだけで十分な場合があります
- 会社支給PCの人：個人で判断せず、情報システム部門に相談してください

## 個人用VPNを選ぶときのチェック項目（運営元・ログ方針・対応端末・同時接続数・解約条件・速度への影響）

VPNが必要だと判断したら、次の項目を各社の公式サイトで確認しましょう。料金だけで選ぶと、「使いたい端末に対応していなかった」「解約しにくかった」といった失敗が起こりがちです。

| チェック項目 | 確認するポイント |
|---|---|
| **運営元** | 運営会社名と所在地が明記されているか。問い合わせ窓口や日本語サポートはあるか |
| **ログ方針** | 通信内容や接続記録をどこまで保存するか。プライバシーポリシーに具体的に書かれているか |
| **対応端末** | Windows・Mac・iPhone・Androidなど、使いたい端末とOSのバージョンに対応しているか |
| **同時接続数** | PCとスマホなど、同時に何台まで接続できるか |
| **IPアドレスの種類** | 固定IPが必要か、接続のたびにIPが変わる共有IPでよいか |
| **サーバーの場所** | 日本のサーバーが必要か、海外の複数の国のサーバーが必要か |
| **解約条件** | 最低利用期間、解約方法（Webで完結するか）、返金保証の有無と条件 |
| **速度への影響** | 速度低下の可能性について説明があるか。無料お試しや返金保証で事前に確認できるか |

フリーランスのWebデザイナーであれば、特に**「対応端末」「速度への影響」「解約条件」**を重点的に確認するとよいでしょう。大容量のデザインデータを扱うことが多く、作業用PCとスマホの両方で使いたい場面が多いからです。

また、無料VPNの中には、運営元やログ方針が不明確なものもあります。クライアントのデータを扱う用途であれば、運営元と方針がはっきりしているサービスを選ぶのが無難です。

### マイIPが向いている人

- **クライアントのシステムがIP制限をかけている人：** 接続元IPアドレスで制限された管理画面やサーバーに、カフェやコワーキングからでも同じIPアドレスで接続したい場合、固定IPがあると許可リストに登録してもらいやすくなります（登録できるかどうかは、事前にクライアント側へ確認してください）

### マイIPを選ばないほうがいい人・代替案

固定IPが特に必要ない人にとっては、マイIPの強みである「日本の固定IP」を活かしにくい可能性があります。たとえば、「海外の複数の国のサーバーに切り替えて使いたい」「家族の端末も含めて多くの台数で使いたい」といったニーズが中心なら、海外サーバーの数や同時接続数を重視した一般的なVPNサービスと、各社の公式情報を比べてみるとよいでしょう。また、チェックリストの【B】に当てはまる人は、テザリングの活用と無料の基本対策だけで十分な場合もあります。会社支給のPCで作業している人は、個人向けVPNではなく会社指定の方法を使ってください。

## まとめ：自分の作業スタイルに合った対策を選ぼう

フリーWi-Fiのリスク対策は、「VPNを入れるかどうか」だけで決まるものではありません。

1. **まずは無料の基本対策から：** HTTPSの確認、自動接続オフ、OS更新、ファイル共有オフ、テザリングの活用、多要素認証、画面ロック
2. **VPNの役割を正しく理解する：** VPNはフリーWi-Fi上の通信を暗号化しますが、フィッシングやマルウェア、画面の盗み見は防げません。通信速度が低下する場合があることも覚えておきましょう
3. **会社支給PCは会社のルールが最優先：** 個人用VPNは入れず、情報システム部門に確認する
4. **チェックリストで要・不要を判断する：** フリーWi-Fiで機密データを扱う機会が多い人や、IP制限・海外からの接続に対応したい人はVPNを検討する

チェックリストで「VPNが必要」に当てはまり、固定IPでの接続にもメリットを感じる人は、マイIPの公式サイトで対応端末・ログ方針・料金・解約条件を確認してみてください。

## よくある質問

### Q1. パスワード付きのフリーWi-Fiなら安全ですか？

パスワードがかかっていて通信が暗号化されていれば、パスワードなしのWi-Fiよりはリスクを抑えられます。ただし、店内にパスワードが掲示されている場合は、同じパスワードを知っている人が多数いることになります。偽のアクセスポイントのリスクもあるため、HTTPSの確認や自動接続オフなどの基本対策は、パスワード付きのWi-Fiでも続けましょう。

### Q2. VPNを使うと通信は遅くなりますか？

遅くなる場合があります。暗号化の処理やVPNサーバーを経由する分、通信速度に影響が出ることがあり、その程度は利用環境やサービスによって異なります。大容量のファイルを扱う人は、お試し期間や返金保証の有無を公式サイトで確認し、実際の作業環境で問題がないか試してから本格的に使うと安心です。

### Q3. スマホのテザリングを使えばVPNは不要ですか？

重要な作業をすべてテザリングで行えるなら、フリーWi-Fiを経由しない分、VPNなしでも対応できる場合があります。一方で、データ容量の上限や速度の都合でフリーWi-Fiを使わざるを得ない人や、クライアントから固定IPでの接続を求められている人は、VPNを検討する余地があります。記事内のチェックリストで、自分の作業スタイルに当てはめて判断してみてください。
