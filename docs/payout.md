# 広告収益を自分の口座に自動で振り込んでもらう手順

アフィリエイト報酬は、このリポジトリではなく **各 ASP（A8.net、もしもアフィリエイトなど）から振り込まれます**。
振込先の口座を ASP に一度登録しておけば、成果が確定して支払い条件を満たしたタイミングで毎回自動的に振り込まれます。
AI やこのリポジトリが口座情報を扱う必要はありません（扱わせない設計にしています）。

## あなたがやること（各 ASP で1回だけ）
1. ASP の管理画面にログイン
2. 「登録情報」「口座情報」「振込先」などの設定画面を開く
3. 振込先口座（銀行名・支店・口座種別・口座番号・名義）を登録する
4. 本人確認・税務情報（インボイス登録の有無など）の入力を求められたら登録する
5. 最低支払額・支払日・振込手数料の扱いを確認する（ASP ごとに違います）

`config.yaml` の `programs` にある全 ASP で同じ設定をしてください。

## やってはいけないこと
- 口座番号・暗証番号・ログインパスワードを、`config.yaml`・Issue・PR・GitHub Secrets・AI へのチャットに書かない
  - `affteam/llm.py` は、口座情報らしき文字列を含むプロンプトの送信を自動で止めます
- ASP のログイン情報を AI に渡して、自動ログインさせない

## 入金の確認
- ASP の「支払明細」CSV を `data/metrics/asp/` に置けば、週次レポートで確定報酬も集計されます
- 実際の入金は通帳・ネットバンキングで確認してください

## 税金について（一般的な情報）
会社員の副業として所得（売上から経費を引いた額）が年間20万円を超えると、一般的に確定申告が必要です。
個別の判断は税務署か税理士に確認してください。
