# X でフォローするアカウントの選び方（手動）

## 自動フォローをしない理由
X のヘルプセンター「[About following on X](https://help.x.com/en/using-x/x-follow-limit)」では、次の行為を規約違反の対象として挙げています。
- 短時間に関係のないアカウントを大量にフォロー・フォロー解除すること（特に自動化した場合）
- フォローしてはすぐ外して、フォロワー数を増やそうとすること（フォローチャーン）
- 他のアカウントのフォロワーを丸ごとフォローすること

相互フォローを自動で増やす仕組みは、作ったばかりのアカウントほど凍結されやすいため、使いません。
フォローは **あなたが手動で、1日10件まで** を目安に行ってください。

## フォローする候補（検索して公式マークを確認してからフォロー）
| 分類 | 検索する名前 | フォローする理由 |
|---|---|---|
| 公的機関（セキュリティ） | 総務省 ／ IPA（情報処理推進機構） ／ 内閣サイバーセキュリティセンター（NISC） | 公衆Wi-Fi・不正ログインの注意喚起を、記事やリサーチのネタにする |
| 公的機関（広告ルール） | 消費者庁 | 景品表示法・ステマ規制の最新情報 |
| 提携先の公式 | GMOとくとくBB ／ UQ WiMAX ／ インターリンク | キャンペーンや仕様変更をいち早く知る（記事の情報更新に使う） |
| ASP | A8.net | 規約やルール変更のお知らせ |
| 在宅ワーク・テレワークの情報 | 「テレワーク」「リモートワーク」「在宅ワーク」で検索し、継続的に情報を発信しているメディア・企業の公式アカウント | 読者の悩みや話題を知る |

**フォローするときの確認ポイント**
- 公的機関・企業は、**公式マーク（グレーや金色のチェック）** があるかを確認する（なりすましに注意）
- 直近1か月以内に投稿がある、活動中のアカウントを選ぶ
- 「相互フォロー」「フォロバ100%」をうたうアカウントはフォローしない（関係のないフォロワーが増えても、記事のクリックにはつながらないため）

## フォロワーを増やす正攻法
- 毎日の自動投稿（記事の告知）に加えて、**週1〜2回は手動で、リンクなしの役立つ投稿** をする（例: 出発前チェックリストの抜粋）
- 「#テレワーク」「#在宅ワーク」などの話題に、手動で **役に立つ返信** をする
- 記事の中で、X アカウントをフォローしてもらえるよう案内する（サイト側の改善として今後実装）
