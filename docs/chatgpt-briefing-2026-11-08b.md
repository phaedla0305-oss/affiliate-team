## ChatGPT の返答の取り込み方
返ってきた JSON を Claude Code に「ChatGPTの返答を取り込んで」と貼ってください。Claude が次のように扱います。
- `title_ideas` → Search Console の数字（表示回数・検索CTR）がたまってから、タイトル改善の候補として検証する
- `keyword_seeds` → 次回の企画（月曜9:00）に渡す調査データに追加する
- `value_posts` → 数値・規約を検証してから、リンクなしの投稿として使う（手動投稿、または投稿キューに追加）
