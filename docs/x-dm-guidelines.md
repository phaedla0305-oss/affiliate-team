# X（@zaitaku_toolbox）DM 対応ルール

ChatGPT 第6報の提案をもとに、Claude が確認して確定（2026-11-10）。

## 基本
- **返信は運営者が確認してから送る**。AI（ChatGPT・Claude）は下書きまで
- DM の自動取得・自動返信・一括送信はしない（X は求められていない自動DMを禁止）
- DM の内容を AI に共有するときは、**氏名・連絡先・契約情報・ログイン情報を消してから**要点だけを渡す

## 場面別の対応
| 場面 | 対応 | 送る前に確認すること |
|---|---|---|
| 読者の回線・VPN の相談 | 用途・困っている場面・今の接続方法など、必要最小限だけ聞く。住所や契約番号は聞かない。まず DM の中で役立つ要点を答える | 個別の環境で「速くなる」「つながる」と保証していないか。勤務先のルールに反する方法（制限の回避など）を案内していないか |
| 記事を紹介する | 追加の説明を求められたときだけ、関連する記事の **通常のURL**（`https://phaedla0305-oss.github.io/zaitaku-toolbox/articles/…`）を案内する。広告を含む記事なら、その旨を一言添える | **A8 の広告リンクや短縮した広告リンクは DM に貼らない**（A8 は個人宛のメッセージでの広告掲載を禁止している）。記事の紹介が広告配信にあたるか迷う場合は A8 に確認する |
| 営業・提携・記事掲載の依頼 | その場で返事をしない。依頼内容・対価・掲載条件・修正権・広告表記を聞く。採用と契約は運営者が判断 | 相手が実在する企業・人か公式サイトで確認したか。既存の ASP の規約と衝突しないか。PR 表記が必要か |
| 送金・ログイン・外部リンク・添付ファイル | **その場で操作しない**。リンクは開かず、必要なら公式サイトを自分で開いて確認する | 見慣れないドメイン、短縮URL、前払いの要求、認証コードの要求、「至急」などの急かす表現 |
| 不審・迷惑な相手 | 返信しない。必要ならブロック・報告 | — |

## 記録
- 個人を特定しない形で「相談のテーマ・回答日・根拠にした情報」だけを記録する（例：「テザリングの通信量の確認方法 ／ 11/10 ／ 記事⑤の手順」）
- DM の件数を、集客や売上の成果として扱わない
- よくある質問は、記事の改善候補（FAQ の追加など）として Claude に共有する

## AI に下書きを頼むときの例文
```
次の DM への返信案を作ってください。運営者が確認してから送ります。
- 相談の要点（個人情報は削除済み）：〇〇
- 守ること：保証しない／広告リンクを貼らない／必要なら記事の通常URLを1つだけ案内／広告を含む記事ならその旨を添える／120字前後
```
