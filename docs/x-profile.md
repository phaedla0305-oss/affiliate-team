# X プロフィール作成キット（@zaitaku_toolbox）

ChatGPT（画像生成が使えるプラン）で、プロフィール写真・ヘッダー画像・自己紹介文を作るためのプロンプトです。
上から順に、ChatGPT のプロジェクト「在宅ワーク道具箱」で使ってください。

## X の画像サイズ（目安）
| 画像 | 推奨サイズ | 注意 |
|---|---|---|
| プロフィール写真 | 400×400px（正方形） | 丸く切り抜かれる。四隅は見えない |
| ヘッダー画像 | 1500×500px（3:1） | 左下にプロフィール写真が重なる。上下も端末によって少し切れる |

---

## 1. プロフィール写真（アイコン）

```
X（旧Twitter）のプロフィール写真を作ってください。

# サイト
「在宅ワーク道具箱」— 在宅ワーク・リモートワークの回線、VPN、作業環境の選び方を、公式情報をもとに解説する情報サイト

# 条件
- 正方形（1:1）。丸く切り抜かれても主役が欠けないよう、中央に収める
- モチーフ: 工具箱（道具箱）の中に、ノートPC・Wi-Fiの電波マーク・小さな家が入っているイメージ
- フラットなイラスト。線は太めで、小さく表示しても形がわかる
- 配色: 紺色（#1F3A5F）をベースに、アクセントでオレンジ（#F28C28）。背景は白か、ごく薄いベージュ
- 文字は入れない
- 実在の企業ロゴ・ブランドマーク・キャラクターに似せない
- 写真風・3D風にはしない

3案作って、それぞれの意図を一言で添えてください。
```

## 2. ヘッダー画像

```
同じサイトの X ヘッダー画像を作ってください。さきほど選んだアイコンと同じ配色・タッチでそろえてください。

# 条件
- 横長 3:1（1500×500px相当）
- 左下の約4分の1（幅300px×高さ200px程度）はプロフィール写真が重なるので、重要な要素を置かない
- 内容: 明るい自宅の作業デスク（ノートPC、ホームルーター風の白い箱型の機器、観葉植物、コーヒー）を右寄りに配置。左〜中央は余白多め
- 特定メーカーの製品に見えるデザイン・ロゴは入れない
- 文字を入れる場合は「在宅ワーク道具箱」だけ。日本語の文字が崩れる場合は文字なしで作る
- フラットなイラスト。落ち着いた印象

2案作ってください。
```

文字が崩れて生成された場合は、文字なしの画像を採用してください。

## 3. 自己紹介文

```
X のプロフィールの自己紹介文を5案作ってください。

# 条件
- 末尾に必ずサイトURLを入れる: https://phaedla0305-oss.github.io/zaitaku-toolbox/
- URLを含めて全角換算160文字以内（URLだけで約50文字使うので、本文は約100文字以内）
- 誰に向けた、何のアカウントかが一目でわかる
- 「※投稿には広告（PR）を含みます」相当の表記を必ず入れる
- 誇張・効果の断定（「必ず」「最強」「No.1」など）はしない
- 絵文字は使っても2つまで
```

### Claude からの下書き（そのまま使う場合）
```
在宅ワーク・リモートワークの回線、VPN、作業環境の選び方を、公式情報をもとにわかりやすく解説。毎日12時に記事を紹介しています。※投稿にはPR（広告）を含みます https://phaedla0305-oss.github.io/zaitaku-toolbox/
```

## 4. 反映のしかた（手作業・約5分）
1. x.com で @zaitaku_toolbox にログイン →「プロフィール」→「プロフィールを編集」
2. ヘッダー画像の上のカメラマーク → 画像を選ぶ → 位置を調整して「適用」
3. プロフィール写真のカメラマーク → 画像を選ぶ → 「適用」
4. 「自己紹介」に文章を貼り付けて「保存」
5. 生成した画像の元データは、サイトでも使えるように手元に保存しておく（任意）
